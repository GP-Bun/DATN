# TH Sneaker Store

Vite + React + TypeScript demo shop cho thương hiệu TH.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở trình duyệt tới `http://localhost:5000`.

## Các trang
- Trang chủ: `/`
- Sản phẩm: `/san-pham`
- Chi tiết sản phẩm: `/san-pham/:id`
- Đăng ký: `/dang-ky`
- Đăng nhập: `/dang-nhap`
- Giỏ hàng: `/gio-hang`
- Thanh toán: `/thanh-toan`

## Tính năng
- Danh sách sản phẩm với dữ liệu giả lập
- Thêm vào giỏ, xoá, tính tổng
- Đăng ký/đăng nhập giả lập, hiển thị trạng thái người dùng
- Thanh toán đơn giản và xác nhận đơn hàng
